Notes on the data

  • Built from VisitorSession, VisitorEvent, Users and TelegramEventCounter — the same records that generate the Telegram alerts. Telegram message text itself is not stored.
  • Visitor stats exclude 1,231 sessions whose user agent looks like a bot/crawler. Visitor sessions are per browser tab; one person can create several.
  • “Unique visitors” uses the persistent browser id when available, otherwise IP + user agent, otherwise the session itself — so early months overstate unique visitors.
  • IP / country / device data and “where the pull was run from” only exist for sessions after the July 2026 tracking update.
  • Landing-page data before July 2026 defaulted to /, so the homepage share of entries is overstated for May–June.
  • Session length is start → end beacon; tabs left open in the background inflate long sessions. Durations over 24h are excluded.
  • Immediate-only Telegram alerts (some hero CTA / page-view pings) are counted in the Telegram counters table even if the journey batch never reached Mongo.
  • Every table is also in csv/ for spreadsheet analysis.
